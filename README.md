# FPAA Connect 2.0 — Official Website

Public website of the Falakata Polytechnic Alumni Association (Regd. No. S0058184 of 2025-26).

- Live site: https://www.fpaaconnect.co.in
- Hosting: Vercel (auto-deploys on every push to `main`)
- Member portal / sign-in: https://fpaa-connect.vercel.app/login.html

## Files
- `index.html` — the whole site (styles and scripts inline)
- `assets/` — photos, emblem and portraits
- `favicon.png`, `og-image.jpg` — browser icon and link-preview image
- `robots.txt`, `sitemap.xml` — search engine files
- `vercel.json` — hosting settings
